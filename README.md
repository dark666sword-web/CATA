# بناء APK

## الطريقة 1: GitHub (بدون تثبيت شيء)
1. أنشئ مستودعًا جديدًا على GitHub وارفع كل محتويات هذا المجلد (بما فيها .github).
2. من تبويب Actions شغّل "Build APK".
3. بعد دقائق نزّل الملف app-debug.apk من Artifacts.

## الطريقة 2: على جهازك
نفّذ ./build-local.sh (يحتاج Node و JDK 17 و Android SDK).
